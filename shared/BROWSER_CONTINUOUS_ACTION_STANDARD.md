# 跨岗位浏览器连续动作标准

## 1. 适用范围

本标准用于所有需要数字员工操作浏览器的岗位，包括但不限于平面设计、公众号、视频、客服、资料整理和后续新增岗位。岗位流程可以增加自己的页面识别与业务动作，但不得重复建设另一套等待与动作调度器。

公共实现：

- `scripts/browser_continuous_action_controller.mjs`
- 海报适配：`scripts/poster_chatgpt_browser_fastlane.mjs`

## 2. 核心原则

1. 浏览器连续动作必须在同一次连续执行中完成，不把确定性点击拆成多轮模型判断。
2. 使用条件检测代替固定等待：页面条件满足后立即进入下一动作，不继续等待剩余时间。
3. 业务成果审核与机械动作提速严格分离。提速不得减少、缩小或跳过完整审图，也不得减少其他岗位的成果审核。
4. 页面状态未知、账号验证、付费、权限、目标冲突或安全风险出现时立即停止，不盲目连续点击。
5. 已成功动作不得重复执行。

## 3. 公共执行结构

每个岗位把任务定义为连续步骤，每个步骤包含：

- 状态名称；
- 成功条件；
- 条件最大等待时间；
- 检测间隔；
- 条件满足后执行的唯一动作；
- 动作时限；
- 失败停止条件。

控制器持续检查条件。条件成立后立即执行动作并进入下一步骤；条件未成立时只检查状态，不重复动作。

## 4. 通用动作时限

动作时限只统计“条件已经满足”到“动作执行完成”，不包含网页加载、生图、上传传输和成果审核本身的时间。

| 动作 | 默认目标 |
| --- | --- |
| 页面可用后开始首个业务动作 | 3 秒内 |
| 可提交状态出现后执行提交 | 5 秒内 |
| 结果完成后打开结果 | 2 秒内 |
| 结果查看器打开后请求下载 | 2 秒内 |
| 下载弹窗出现后确认 | 3 秒内 |
| 下载完成后进入本地处理 | 10 秒内 |

动作超过目标但结果仍有效时，继续保留结果并记录 `slaBreached`，不得为了满足指标取消有效成果。

## 5. 海报专属连续链路

海报岗位必须使用两个连续块：

### 上传块

页面可用 → 粘贴素材一次 → 检测正确缩略图 → 返回上传证据 → 执行上传后门禁。

### 生成下载块

上传门禁通过 → 输入并发送提示词 → 检测生成状态 → 生成完成到确认下载全过程连续执行：打开图片 → 点击下载 → 填写文件名 → 确认下载 → 检测文件完成。

正常状态下要求：

- 生成完成后 2 秒内打开图片；
- 查看器打开后 2 秒内点击下载；
- 下载弹窗出现后 3 秒内确认下载。

以上动作之间禁止退出等待下一轮模型判断。

## 6. 动作时间线

每次运行必须保存动作时间线到当前任务的 `temp/` 目录。公共时间线至少包含：

- 连续块开始与完成；
- 每个条件开始等待和满足；
- 每个动作开始与完成；
- 条件等待时长；
- 动作执行时长；
- 动作是否超过时限；
- 失败步骤、错误代码和失败原因。

不得把提示词全文、账号信息、私人素材内容或密钥写入动作时间线。

### 电商套图单会话连续链路

淘宝首图与详情页属于同一套生成任务时，必须采用 `single_conversation_full_set`：

1. 只在首个实际队列项开始前新建一次GPT对话，并保存稳定的会话引用。
2. 后续首图、从首图切换到详情首屏、后续详情屏和当前图片返修，全部在该对话中继续发送；不得点击侧栏新建对话，不得为详情页建立独立会话。
3. 每个上传块开始前核对当前会话引用；首项动作记录为 `opened_new`，后续全部记录为 `reused_existing`。
4. 浏览器连续动作时间线必须记录图片编号、会话引用、会话动作和是否发生页面跳转，但不得记录提示词全文。
5. 找不到原会话、会话引用变化或新建次数超过1时立即停止；不得自动新开对话继续整套。

## 7. 异常与停止

1. 素材上传一次未出现正确缩略图时停止当前方法，执行岗位既有降级规则。
2. 生成仍在正常进行时继续检测，不把生成时间误判为动作卡顿。
3. 找不到结果、下载控件或弹窗时保存一次现场证据并停止。
4. 下载只允许请求一次、确认一次；文件名冲突时停止，不覆盖已有成果。
5. 同一根因连续失败三轮时停止并进入问题管理，不继续增加点击尝试。

## 8. 复用方法

新增岗位只需：

1. 引用本文件；
2. 调用 `runContinuousActionSequence`；
3. 定义自己的 `condition` 与 `action`；
4. 将时间线写入该岗位任务的 `temp/` 目录；
5. 保持该岗位原有成果审核标准。

公共控制器不得包含岗位名称、业务提示词、固定账号或私人路径。
