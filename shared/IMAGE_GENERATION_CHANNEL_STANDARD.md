# AI 生图通道与安全拒绝公共标准

## 1. 适用范围

所有岗位只要调用 AI 生图，都必须读取本标准。岗位 Skill 可以增加业务要求，但不得降低本标准。

## 2. 通道锁定

1. 项目默认正式通道是 **QQ 浏览器中的 ChatGPT 网页**。
2. Codex 内置 `image_gen` 仅在帝王明确授权当前任务、当前版本、当前用途时可用；“允许上传素材”“全面使用素材”“继续制作”均不等于授权更换生图工具。
3. 授权必须执行 `current_job_version_authorization`：记录任务编号、版本、通道、帝王原话和时间。授权不得从其他任务、其他版本或其他网站继承。
4. 不得因为浏览器操作麻烦、等待较久、自动化暂时不便或内置工具更快而擅自换通道。
5. 实际候选使用的通道必须与清单中的当前通道一致；不一致时门禁失败。

## 3. 安全拒绝只限定当前通道

1. 每次拒绝必须记录通道、版本、错误分类、报错原文和时间，执行 `channel_scoped_refusal`。
2. 单一通道、单一提示词或单次输出的拒绝，只能说明该通道对本次请求未能生成；不得升级为项目全局禁令、行业禁令或所有模型禁令。
3. 项目长期禁用项只能依据明确官方规则、帝王决定或多个受控渠道的一致证据，由主流程线程写入长期规则。
4. 同一通道针对同一根因最多执行“首次请求＋一次合规重写”。第二次仍拒绝时停止该通道，不通过替换敏感词、拆分提示或隐晦表达绕过安全系统。
5. 如果错误来自未经授权或误选的非默认实验通道，停止该通道并恢复已经确认的默认生产路线；这属于纠正执行路线，不得演变成跨平台反复试探。默认生产路线也明确拒绝时停止 AI 生图。

## 4. 方向变化必须重新确认

1. 安全降级不得改变帝王已经确认的核心呈现方式。
2. 真人上身改成人台、人物改静物、产品实拍改概念图、完整展示改为遮挡展示，均属于 `confirmed_direction_change`。
3. 方向变化必须使原确认失效，重新记录帝王确认；未确认不得继续生图。
4. 不改变核心方向的合规调整可以直接执行，例如明确成年、改为自然站姿、提高服装遮盖度、删除色情化措辞和避免敏感部位暴露。

## 5. 正常内衣零售内容边界

明确成年模特穿着不透明内衣，在标准服装目录、电商或品牌零售语境中自然展示版型，不是项目全局禁项。可以表现正常肩颈、腰腹和产品所需的穿着轮廓。

必须停止的情况包括：未成年人或年龄不明、透明暴露、可见乳头或生殖部位、性行为、以性刺激为主要目的的姿态、非自愿私密内容、未经授权的真人性化改造。参考图只提取商业视觉方向，不复制人物、品牌、水印或原版排版。

## 6. 失败后的兜底顺序

1. 保留已确认的业务目标，不先改产品展示方式。
2. 检查是否误选通道、授权是否适用、提示词是否把正常零售表达写成色情化表达。
3. 在同一已授权通道最多进行一次合规重写。
4. 默认生产路线明确拒绝后，停止 AI 生图并记录渠道兼容性限制。
5. 优先使用权利清晰的真实产品图、成年模特产品图进行确定性排版合成；需要改变核心方向时先获得帝王确认。

## 7. 多图与提示词负载

1. “需要多张系列”不等于“一次请求生成多张”。默认一条请求只生成一张、一个主要构图和一个主要姿态，系列图逐张执行。
2. 成年贴身服饰强制每次只生成一张；第 1 张通过安全、产品真实性和审美验收后才能成为后续连续性锚点。
3. 每张最多首次请求加一次合规重写；第二次同根因失败后按本标准停止当前通道。
4. 安全要求集中写成一次紧凑安全块，不在多个段落重复堆叠身体、暴露和禁用词；不得以隐晦替换词规避安全系统。
