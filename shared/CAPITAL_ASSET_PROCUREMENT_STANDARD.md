# 固定资产新旧组合采购标准

## 1. 适用范围

当项目涉及设备、器械、车辆、工程设施、生产工具、办公硬件或其他固定资产投入时，五个组织十五个技能、控制中心任务提示和组织成果统一执行本标准。无固定资产投入的任务不强行展开本标准。

## 2. 根本原则

预算不得默认全部买新，也不得为了压低投资额默认全部买二手。AI必须同时形成全新采购、二手采购、混合采购三种可比方案，默认优先评估混合采购，并按安全、合规、经营影响和全生命周期成本选择。

全生命周期成本至少包括：采购价、税费、运输、拆装、安装、整备、检测或认证、维修、耗材、能耗、停机损失、预计使用寿命和残值。不得只比较设备挂牌价。

## 3. 设备分级

### 3.1 原则上购买全新或原厂认证翻新

- 安全关键、消防、急救、承重、防护或事故后果严重的设备；
- 受许可、强制检测、计量、环保、卫生或其他合规要求约束的设备；
- 与客户身体直接接触且难以彻底整备的卫生关键设备；
- 软件授权、云服务、数据安全或厂商账号强绑定的设备；
- 高能耗、高精度、高故障损失或决定核心收入连续性的设备；
- 无法核验来源、序列号、事故史、维保记录、剩余寿命或配件供应的设备。

### 3.2 可以优先比较二手

- 结构简单、磨损可见、性能可现场检测的机械设备；
- 标准化程度高、配件通用、当地维修成熟的设备；
- 技术迭代慢、折旧快于功能衰减、停机不影响核心经营的设备；
- 可通过更换易损件、表面整备和负载测试恢复可靠性的非安全关键设备。

### 3.3 只允许有条件采购二手

带电机、控制板、传感器、制冷系统、液压系统、动力电池或高精度组件的设备，只有在来源、序列号、使用年限、维保记录、故障码、负载测试、能耗、配件供应、整备清单和书面质保均可核验时，才能进入二手候选。

## 4. 三方案强制输出

涉及固定资产预算时，成果必须逐项输出：

1. 全新采购方案：新机价格区间、质保、寿命、能耗、交付周期和残值。
2. 二手采购方案：二手成交区间、运输拆装、整备检测、首年维修准备金、停机风险和残值。
3. 混合采购方案：明确每一类资产买新还是买二手、金额、理由和替代条件。
4. 推荐结论：说明推荐方案相对其他方案节省多少初始投入、三年总成本变化多少、释放多少周转资金，以及承担了什么风险。

精确报价未取得时，先用至少两个公开样本或供应商公开区间建立测算；标明检索日期、地域、成色与税运口径。不得用单一低价挂牌作为可成交价格。

## 5. 二手设备准入门槛

二手设备必须同时满足：

- 卖方身份、资产权属、来源和序列号可核验；
- 无召回、重大事故、泡水、火烧或非法改装记录；
- 使用年限、维保记录、累计工时或里程能够支持剩余寿命判断；
- 完成外观、结构、电气、空载与负载测试，关键磨损件给出限值；
- 常用配件和维修服务至少覆盖预计持有期；
- 合同写明成色口径、验收方法、故障责任、退换条件和质保期限；
- 二手落地总成本原则上不高于可比新机落地成本的70%；计入三年增量维修、能耗和停机损失后，仍至少保留20%的总成本优势。行业证据支持其他阈值时，必须写明依据。

不满足任一安全、合规或权属条件时，即使价格更低也直接淘汰。

## 6. 预算表达

固定资产预算至少拆为：设备本体、税费、运输拆装、安装调试、整备翻新、检测认证、易损件、首年维修准备金和停机备用方案。混合方案节省的资金优先进入经营周转金和风险准备金，不自动扩张装修、面积或设备数量。

## 7. 质量拒绝条件

出现以下任一情况，成果不得通过：

1. 有固定资产投入，却只给一套“全部买新”预算或一个设备总数。
2. 用“可以考虑二手”一句话代替逐项分类、金额和风险判断。
3. 只比较采购价，不计算运输、整备、检测、维修、能耗、停机和残值。
4. 把二手来源搜集、价格比较、验机清单或预算测算交给帝王完成。
5. 为降低预算而建议采购来源、权属、安全或合规无法核验的二手设备。
