# AI掌舵官使用说明

帝王只需描述希望解决的经营问题，例如：

- “分析这家企业现在最关键的三个问题”；
- “制定未来三年的战略方向”；
- “重新设计盈利模式”；
- “把战略、品牌、增长、成交和组织整合成完整系统”。

当前企业分析、战略规划和商业模式三个技能都已经可以试运行：

- 企业分析负责看清现状和核心问题，已经具备项目任务运行时；
- 战略规划负责比较方向、明确取舍和90天行动，已经具备项目任务运行时；
- 商业模式负责连接客户价值、收入成本、交付复购和验证实验，目前是候选级模拟试运行；已经支持持久化、暂停和幂等恢复，但尚无同等级专属规划调试、发布请求和真实商业验证。

系统会依次读取上游结果并核对版本与哈希。无法确认的信息会标成未知项，不会补写虚假数字。

三个技能候选通过检查后仍需要帝王或企业授权人决定是否采用；系统不会自动实施投资、定价、裁员、签约、收费、外联或对外发布。帝王完成本轮最终验收前，三个技能保持`pilot`且不正式接单。
