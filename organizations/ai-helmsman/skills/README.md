# AI掌舵官Skills

当前已建立三个非空、可发现、可执行和可验证的组织Skill：

1. `enterprise-analysis`：企业分析；
2. `strategy-planning`：战略规划；
3. `business-model`：商业模式。

三个技能均已完成统一必需章节、候选契约、质量门禁和自动化测试，当前状态为本地`pilot`，但证据等级不同：

- 企业分析：`evidenceLevel=internal_real`，具备项目规划、运行状态、调试、暂停恢复和发布请求；
- 战略规划：`evidenceLevel=internal_real`，具备项目规划、运行状态、调试、暂停恢复和发布请求；
- 商业模式：`evidenceLevel=simulation`，已具备专属规划、候选调试、完整项目运行、暂停恢复、显式版本修订和发布请求；尚缺真实商业实验和使用者验收。

帝王最终验收及组织状态升级前，不得标记为`formal`，不得把AI掌舵官描述为已正式接单。
